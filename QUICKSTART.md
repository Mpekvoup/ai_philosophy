# 🚀 Быстрый старт AI-Философа

Следуйте этим шагам для запуска приложения:

## 1️⃣ Установка Python пакетов

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте его
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

## 2️⃣ Настройка API ключа

1. Получите Google Gemini API ключ:
   - Перейдите на https://makersuite.google.com/app/apikey
   - Войдите с Google аккаунтом
   - Создайте новый API ключ

2. Создайте файл `.env`:
```bash
cp .env.example .env
```

3. Откройте `.env` и вставьте ваш API ключ:
```env
GEMINI_API_KEY=ваш_ключ_здесь
```

## 3️⃣ Инициализация базы данных

```bash
python manage.py migrate
```

## 4️⃣ Запуск сервера

```bash
python manage.py runserver
```

## 5️⃣ Открытие приложения

Откройте в браузере (Chrome или Edge):
```
http://localhost:8000
```

## 6️⃣ Использование

1. Нажмите кнопку микрофона
2. Разрешите доступ к микрофону
3. Задайте философский вопрос голосом
4. Получите мудрый ответ!

---

## ⚠️ Важно

- **Браузер**: Используйте Chrome или Edge (Safari не поддерживается)
- **Микрофон**: Разрешите доступ при первом запуске
- **API ключ**: Обязательно добавьте ключ Gemini в .env
