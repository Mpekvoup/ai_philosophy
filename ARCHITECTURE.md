## Поток данных

### 1. Захват речи (Frontend)
```
Пользователь говорит 
  ↓
Web Speech API слушает
  ↓
Распознавание речи → ТЕКСТ
  ↓
JavaScript получает текст
```

### 2. Отправка запроса (Frontend → Backend)
```
JavaScript
  ↓
fetch('/api/ask/', {
  method: 'POST',
  body: JSON.stringify({ question: "текст" })
})
  ↓
Django views.py
```

### 3. Обработка (Backend)
```
views.ask_philosopher()
  ↓
Валидация вопроса
  ↓
PhilosopherAI.get_philosophical_response()
  ↓
Формирование промпта (system + user question)
  ↓
genai.GenerativeModel.generate_content()
```

### 4. AI обработка (Google Gemini)
```
Получение запроса
  ↓
Анализ контекста (философский промпт)
  ↓
Генерация ответа
  ↓
Возврат текста
```

### 5. Ответ пользователю (Backend → Frontend)
```
Django возвращает JSON
  ↓
JavaScript получает ответ
  ↓
Обновление DOM
  ↓
Отображение ответа пользователю
```

## Компоненты системы

### Frontend (Client-Side)

#### index.html
- Структура страницы
- UI элементы (кнопки, области отображения)
- Подключение стилей и скриптов

#### style.css
- Современный дизайн с темной темой
- Адаптивная верстка
- Анимации и переходы
- Визуальная обратная связь

#### app.js (PhilosopherApp класс)
- **setupSpeechRecognition()** - инициализация Web Speech API
- **startRecording()** - запуск распознавания речи
- **onRecognitionResult()** - обработка результатов
- **sendQuestionToServer()** - отправка AJAX запросов
- **addToHistory()** - управление историей диалога
- **updateStatus()** - обновление статуса

### Backend (Server-Side)

#### settings.py
- Конфигурация Django
- Подключение приложений
- Настройки статических файлов
- Загрузка переменных окружения

#### urls.py (главный)
- Маршрутизация запросов
- Подключение приложения philosopher

#### philosopher/urls.py
- `GET /` - главная страница
- `POST /api/ask/` - API endpoint

#### philosopher/views.py
- **index()** - отображение главной страницы
- **ask_philosopher()** - обработка API запросов
  - Валидация JSON
  - Вызов AI клиента
  - Обработка ошибок

#### philosopher/gemini_client.py
- **PhilosopherAI класс**
  - `__init__()` - инициализация Gemini
  - `get_philosophical_response()` - генерация ответов
  - `system_prompt` - философский контекст

### External Services

#### Google Gemini Cloud API
- Model: gemini-1.5-flash
- Быстрая генерация текста
- Понимание контекста
- Философские знания

#### Web Speech API
- Встроена в Chrome/Edge
- Real-time распознавание
- Поддержка русского языка
- Промежуточные результаты

## Безопасность

### Frontend
- Валидация пользовательского ввода
- Обработка ошибок API
- Безопасное отображение контента

### Backend
- CSRF защита (Django middleware)
- Валидация JSON данных
- Обработка исключений
- Защита API ключей (.env)

### API
- Ключ в переменных окружения
- Не передается на frontend
- Ограничение запросов (rate limiting)

## Масштабируемость

### Текущая архитектура
- Синхронные запросы
- Одиночный сервер
- SQLite база данных
- Без кэширования

### Возможные улучшения
1. **Асинхронная обработка**
   - Использование Django Channels
   - WebSocket для real-time

2. **Кэширование**
   - Redis для часто задаваемых вопросов
   - Кэш ответов Gemini

3. **База данных**
   - PostgreSQL для продакшена
   - Сохранение истории диалогов

4. **Балансировка нагрузки**
   - Nginx
   - Gunicorn workers

5. **Мониторинг**
   - Логирование запросов
   - Аналитика использования
   - Отслеживание ошибок
