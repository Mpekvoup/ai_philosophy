# 💬 Примеры использования AI-Философа

## Философские вопросы

### О смысле жизни
- "В чем смысл жизни?"
- "Зачем мы живем?"
- "Есть ли у жизни цель?"

### О счастье
- "Что такое счастье?"
- "Как достичь счастья?"
- "Можно ли быть счастливым всегда?"

### О познании
- "Что такое истина?"
- "Можем ли мы познать реальность?"
- "Что важнее: знание или мудрость?"

### О свободе
- "Существует ли свобода воли?"
- "Что такое настоящая свобода?"
- "Можем ли мы быть по-настоящему свободными?"

### О морали и этике
- "Что такое добро и зло?"
- "Откуда берется мораль?"
- "Существует ли абсолютная мораль?"

### О сознании
- "Что такое сознание?"
- "Кто я?"
- "Что делает меня мной?"

### О времени
- "Что такое время?"
- "Существует ли настоящее?"
- "Можно ли изменить прошлое?"

### О любви
- "Что такое любовь?"
- "Почему мы любим?"
- "Может ли любовь быть вечной?"

### О смерти
- "Что происходит после смерти?"
- "Почему мы боимся смерти?"
- "Имеет ли смерть смысл?"

### О технологиях и AI
- "Может ли машина думать?"
- "Что такое искусственный интеллект?"
- "Опасен ли AI для человечества?"

## Ожидаемые ответы

AI-Философ будет давать ответы в стиле:

**Вопрос:** "В чем смысл жизни?"

**Возможный ответ:** 
"Сократ учил нас, что неисследованная жизнь не стоит того, чтобы быть прожитой. Смысл жизни каждый находит сам через поиск истины, добродетели и самопознания. Возможно, сам процесс поиска смысла и есть смысл жизни."

---

**Вопрос:** "Что такое счастье?"

**Возможный ответ:**
"Аристотель называл счастье эвдемонией - состоянием полного расцвета человеческих способностей. Это не мимолетное удовольствие, а глубокое чувство удовлетворенности от жизни в соответствии со своими ценностями и реализации своего потенциала."

## Советы по использованию

### Для лучшего распознавания речи:
1. Говорите четко и не торопясь
2. Минимизируйте фоновый шум
3. Используйте качественный микрофон
4. Делайте паузу после окончания вопроса

### Формулирование вопросов:
1. Задавайте открытые вопросы
2. Будьте конкретны в своих формулировках
3. Избегайте слишком длинных вопросов
4. Один вопрос за раз

### Взаимодействие:
1. Дождитесь полного ответа перед следующим вопросом
2. Используйте историю диалога для контекста
3. Можете задавать уточняющие вопросы
4. Экспериментируйте с разными темами

## Технические детали

### Языки распознавания:
- Основной: Русский (ru-RU)
- Для изменения языка отредактируйте `app.js`:
  ```javascript
  this.recognition.lang = 'ru-RU';  // Измените на нужный
  ```

### Настройка промпта:
Для изменения стиля ответов отредактируйте `gemini_client.py`:
```python
self.system_prompt = """
Ваш кастомный промпт здесь...
"""
```

## Ограничения

1. **Браузер**: Только Chrome и Edge
2. **Интернет**: Требуется постоянное подключение
3. **Язык**: По умолчанию русский
4. **Длина**: Краткие ответы (2-4 предложения)

## Расширенные возможности

### Добавление новых языков:
Отредактируйте `app.js` и добавьте селектор языка:
```javascript
this.recognition.lang = document.getElementById('langSelect').value;
```

### Настройка длины ответов:
В `gemini_client.py` измените промпт:
```python
"3. Понятными для широкой аудитории"
"4. Краткими (2-4 предложения)"  # Измените здесь
```

### Добавление голосового вывода:
Используйте Web Speech Synthesis API для озвучивания ответов.
